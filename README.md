# Mother's Lesson
A Unity game created for class IMG421 3D-Game Engines at NAU to familiarize myself with wave systems in Unity. A game where you play as a mother duck teacher her ducklings how to forage.

## Controls
Use WASD or Arrow Keys to Move around the pond, collecting apples. 

Collect apples just by running into them. 

Press Q to Quack

## Extra Credit
(1.5) Add a background in the Sky AND use Unity's built-in terrain system to make a terrain along with the water.
 
(0.5) Add SFX. SFX is added through water sounds when moving, quacking, and apple crunch when collecting apples.
